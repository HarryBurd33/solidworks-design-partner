| Synthetic output | Parent produced by inspected logic |
|---|---|
| `C:\plate.SLDPRT` | `C:\` |
| `C:\work\plate.SLDPRT` | `C:\work` |
| `\\server\share\plate.SLDPRT` | `\\server\share` |
| `\\server\share\folder\plate.SLDPRT` | `\\server\share\folder` |

The drive-root repair applies only to the drive prefix; it leaves ordinary nested paths and UNC parent strings intact. The attribute check rejects a file masquerading as a parent directory.
